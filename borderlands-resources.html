Matt's SDK Boosting Tools

Windows desktop app for Borderlands 4 boosting and item tools. Electron runs outside the game; a small SDK mod handles live actions over a bridge. Browse BL4 Codes, deliver serials (with copies), run UVH boosters, host Mattmab’s editor, spawn actors, travel, and more.

Download latest releaseGitHub README & install stepsGet oak2-mod-manager v0.3Get Discord help

Needs Borderlands 4 on PC and oak2-mod-manager v0.3. After an SDK mod update, fully restart the game. Back up saves before editor work. Downloads and release notes live on GitHub so you can verify the current version.
