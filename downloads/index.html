What's new in 0.5.3

Updating the desktop app? After installing 0.5.3, close Borderlands 3, update the bundled Funk SDK to 0.5.1 from Setup / About, then relaunch the game.

  • Preview and run a saved boost profile for one selected player, or set up an AFK profile for joining guests. Supported targets read the current total and grant only the shortfall.
  • Guardian profiles can target rank, unspent tokens, and reward investments. The preview shows how spending affects the token balance.
  • Eligible Skills cards show the selected player's active or purchased rank. Add and Target drafts are saved separately. Review older Add profiles before converting them to targets.
Compatibility and known limits

AFK is experimental and requires you to start it in each new game session. The host can verify some changes during the session. Guest save persistence remains unverified.

Purchased-rank reads for passive augments and fast skill delivery require the verified Windows x64 Steam build of Borderlands 3. Other game builds and Proton remain unverified. Automatic guest cosmetic unlocks and exact item ownership targets are unavailable.
