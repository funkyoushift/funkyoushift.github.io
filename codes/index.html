About this collector

This is the FunkYouBoostingTools community codes desk for Borderlands 3, hosted on funkyoushift.com. It is not a Borderlands 4 page and not save-editor.be. Downloads and updates live on GitHub. Seeded names and serials come from the public Lootlemon BL3 database. Cards use placeholders when there is no community screenshot.

Owner review: review.html on this domain. With the Cloudflare collector it uses the review key; without it, load data/submissions.json or a downloaded JSON. Locally you can also run node review.js pending. Approved rows go into data/community.json.
