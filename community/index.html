How to use Borderlands 4 item codes

  1. Search for a folder or creator and choose Preview folder.
  2. Inspect the item names and subfolders, then copy an individual serial, copy all codes, or download the collection.
  3. To import a collection into MSBT, copy its folder link and open Bookmarks → Community folders. Azzy users with the community add-on can use IMPORT LINK in the Codes screen.

For tools that accept BL4 serials, check their supported formats and item limits before importing. See the Borderlands 4 save editor and item tools directory for related tools. This library stores shared collections; it does not edit a save file in your browser.

Community library questions

Are these Borderlands 4 SHiFT codes?

No. These are encoded @U item serials for compatible item tools and SDK mods. SHiFT reward codes are a different system and cannot be redeemed here.

Can I find gear for Vex, Rafa, Amon, Harlowe, C4SH, or Loveless builds?

Search a Vault Hunter name in collection titles, or search a creator. Results depend on the approved community submissions currently available. Use the Borderlands 4 builds page for skill planners and creator videos.

Do I need an account to download item codes?

No. Anyone can browse approved folders, copy serials, and download collections. Admin sign-in is only for team review and management.

Can I add the library to my own app or SDK mod?

Yes. The Borderlands 4 community API provides public read access with JavaScript and Python clients. Keep serial case, item order, duplicate entries, and folder paths intact.
