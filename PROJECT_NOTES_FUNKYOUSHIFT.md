# PROJECT_NOTES_FUNKYOUSHIFT.md

## Project purpose
FunkYouSHiFT.com is the official creator/brand hub for FunkYouSHiFT. The site should route visitors quickly to Discord, Twitch/content, merch, giveaways, gallery, socials, and support links.

## Current conversion priority
1. Discord community joins
2. Merch clicks/sales
3. Embedded stream/content views
4. Social follows and support links

## Voice / copy rules
- Sound like Funk: direct, funny, slightly chaotic, helpful, not corporate.
- Avoid weird over-themed phrases that normal humans would not say.
- Keep public page copy clear: what the visitor gets and where to click.
- Strong phrases that fit: “people who actually answer,” “rep the chaos,” “home base,” “grab the merch,” “keep up with everything Funk.”

## Site rules
- Make real file changes, not just suggestions.
- Preserve existing file names unless intentionally changing site structure.
- Keep paths simple for static hosting: index.html, style.css, images/.
- When adding images, copy them into /images and reference them by relative paths.
- Avoid sending patch ZIPs that omit required CSS or image assets if the page depends on them.
- Update this notes file and CHANGELOG_FUNKYOUSHIFT.md after meaningful changes.

## SEO / schema rules
- Homepage should define FunkYouSHiFT as creator/entity, site hub, and community.
- Keep Open Graph image pointed to a real image in /images.
- Maintain robots.txt, sitemap.xml, and llms.txt.
